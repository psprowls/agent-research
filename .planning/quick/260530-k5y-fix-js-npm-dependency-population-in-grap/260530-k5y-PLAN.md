entire dependency-node/edge emission block is gated on `if info["language"] == "python":`

that distinguishes `devDependencies` from runtime `dependencies`.

Purpose: JS workspaces (the project's own MCP/CLI surface and any consumed
package.json packages) appear correctly in the dependency graph at parity with
Python, including version specifiers and runtime-vs-dev distinction.

a DERIVER_VERSION bump, and new tests proving JS dep parity.

Shared accumulators in refresh() (packages.py ~195-204), language-agnostic:
  dep_acc: dict[(ecosystem, name)] -> {"versions_in_use": [str, ...]}
  used_by_pairs: list[(consumer_name, consumer_rel_path, consumer_kind, dep_name)]

accumulators. Do NOT duplicate it. Only the per-language COLLECTION feeding the
accumulators must be added for JS.
