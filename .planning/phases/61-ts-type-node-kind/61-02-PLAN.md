## Task 1: Add `type` to cross-kind resolution

<read_first>
- packages/graph-io/src/graph_io/resolve.py
</read_first>

<action>
In `resolve.py`:
1. Change `_CROSS_KIND_RESOLVABLE = frozenset({"function", "method", "class"})` to
   `frozenset({"function", "method", "class", "type"})`.
2. Change the inline cross-kind SQL `kind IN ('function', 'method', 'class')` to
   `kind IN ('function', 'method', 'class', 'type')`.
This lets a `type` placeholder export-edge destination (and bare re-exports defaulted to
`function`) resolve to a real `type` node when exactly one such node of that name exists
graph-wide.
</action>

<acceptance_criteria>
- `from graph_io.resolve import _CROSS_KIND_RESOLVABLE; assert "type" in _CROSS_KIND_RESOLVABLE`
- The cross-kind SQL string literal in `resolve.py` contains `'type'` inside the `kind IN (...)` clause.
- `cd packages/graph-io && uv run python -c "from graph_io.resolve import _CROSS_KIND_RESOLVABLE; assert 'type' in _CROSS_KIND_RESOLVABLE; print('ok')"`
- grep confirms no remaining `kind IN ('function', 'method', 'class')` (without `type`) in resolve.py.
</acceptance_criteria>

## Task 3: Add `type` to the queries `_VALID_KINDS` allowlist

<read_first>
- packages/graph-io/src/graph_io/queries.py (the `_VALID_KINDS = frozenset(...)` definition at line ~9; the enforcement `if kind is not None and kind not in _VALID_KINDS: raise ValueError(...)` at line ~264)
</read_first>

<action>
In `queries.py`, add `"type"` to the `_VALID_KINDS` frozenset (the allowlist used by the
`find` query to reject unknown `--kind` filters). Without this, `cg find --kind type`
(and `find(kind="type")`) raises `ValueError("unknown kind 'type'; valid: ...")` and the
new node kind is unqueryable. Do NOT touch `_VALID_APP_KINDS` (that is the app-subtype
allowlist — unrelated to node kinds). Do NOT add a dedicated `cg describe-type` command
(out of scope — `find --kind type` plus traversal is the intended graph surface).
</action>

<acceptance_criteria>
- `from graph_io.queries import _VALID_KINDS; assert "type" in _VALID_KINDS`
- `cd packages/graph-io && uv run python -c "from graph_io.queries import _VALID_KINDS; assert 'type' in _VALID_KINDS; print('ok')"`
- `find(kind="type")` (or `cg find --kind type`) does NOT raise `ValueError` for an unknown kind.
</acceptance_criteria>
